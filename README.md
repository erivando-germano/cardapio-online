# Cardápio Online - Sistema de Pedidos para Pizzaria

## Descrição

O sistema de cardápio online é uma plataforma que permite aos usuários visualizarem, escolherem e realizarem pedidos de produtos de uma pizzaria. O sistema utiliza um banco de dados MySQL para armazenar informações sobre produtos, pedidos e clientes.

## Funcionalidades

- **Visualização do Cardápio:** Os usuários podem visualizar o cardápio completo da pizzaria, incluindo descrições e preços dos produtos.

- **Cadastro de Produtos:** A administração pode adicionar, editar ou excluir produtos do cardápio através do sistema.

- **Realização de Pedidos:** Os clientes podem adicionar produtos ao carrinho, especificar detalhes adicionais (como preferências de cobertura) e enviar seus pedidos.

- **Cadastro de Clientes:** Os clientes podem se cadastrar no sistema para terem uma experiência personalizada e rastrear seus pedidos anteriores.

- **Gestão de Pedidos:** A administração pode visualizar e gerenciar os pedidos recebidos, marcando-os como processados ou entregues.

- **Pagamento na Entrega:** Os clientes têm a opção de pagar pelos pedidos apenas no momento da entrega.

## Tecnologias Utilizadas

- **Node.js:** Plataforma para execução do backend do sistema.
- **Express.js:** Framework web para Node.js, utilizado na construção das rotas.
- **MySQL:** Banco de dados relacional utilizado para armazenar informações sobre produtos, pedidos e clientes.
- **HTML/CSS/JavaScript:** Utilizados na construção do frontend da aplicação.

## Instalação

1. Clone o repositório: `git clone https://github.com/seu-usuario/nome-do-repositorio.git`
2. Instale as dependências: `npm install`
3. Configure as variáveis de ambiente, incluindo as credenciais de conexão com o MySQL.
4. Execute os scripts SQL no banco de dados para criar as tabelas necessárias.
5. Inicie o servidor: `npm start`

## Configuração do Banco de Dados

Certifique-se de ter um servidor MySQL em execução e configure as variáveis de ambiente ou o arquivo de configuração com as credenciais corretas para a conexão com o banco de dados.
